# Media: images, videos and their sources

The pictures and videos of moa7amed-queue, a Claude Code plugin, used by the README and
[the demo page](../demo.md). Everything here was made for this repository; nothing is
downloaded or licensed from elsewhere.

## What is here

| Folder | Content | Tracked in git |
| :-- | :-- | :-- |
| `images/` | Diagrams (`*.svg` and their `*.png` renders), terminal screenshots (`*.png`), the video thumbnail, `ALT.json` (alt text of every image) | yes |
| `video/` | Silent VP9 WebM videos with burned-in captions, and WebVTT caption files (`*.en.vtt`, `*.ar.vtt`) | yes (each under 4 MB) |
| `source/` | The recorder, the renderers, the verification script, the storyboard and narration, the recorded session (`session/session.json`) and the verification result | yes |

Not tracked, and not to be added: the demo workspace the recorder creates (a synthetic
project and a throwaway queue, outside the repository), raw or intermediate frames, and
any larger recording. A future video that is too large for the repository (more than a
few MB) belongs in a GitHub release as an asset, uploaded by the owner when a release is
published; the README then links to that asset. No such upload has been made.

## How the media were made

| Kind | How | Labelled as |
| :-- | :-- | :-- |
| Terminal screenshots | `source/record_demo.py` ran real commands with the real Claude Code CLI on a synthetic project and stored each command's exact output; `source/render_media.py images` lays that text out in a terminal frame with Chromium. Lines may be left out (a "⋯ N lines not shown" marker says so); no line is changed or added; colours are applied to existing words | "Real output · recorded <date> · Claude Code <version> · synthetic project" |
| Diagrams | Hand-written SVG, rendered to PNG with Chromium (`source/svg_to_png.py`) | "Diagram" |
| Videos | `source/render_media.py video` replays the same recorded session: commands are typed out, outputs appear as recorded; long waits are compressed | "Real output, replayed"; "Sped up ×N · X s shown in Y s"; "Runner killed here (on purpose)" |
| Captions | Written by hand per scene in `source/render_video.py` (English and Arabic), burned into the videos and written as WebVTT | — |

The recording was made on a machine whose host name the plugin printed; the recorder
therefore runs the plugin through `source/demo_host.py`, which reports the host name as
`demo-pc` and changes nothing else. Claude Code session ids printed by `show` were
replaced by `(session id removed)` in `session.json` (recorded in its `redactions` field).
The demo workspace used a neutral path (`G:\mq-demo\take3`); no user-home path, account,
e-mail address, credential or customer data appears.

## Rebuilding

```bash
python docs/media/source/record_demo.py --root <empty folder with a neutral path> --budget 2.00   # costs money
python docs/media/source/svg_to_png.py
python docs/media/source/render_media.py images
python docs/media/source/render_media.py video          # also writes storyboard.md
python docs/media/source/verify_media.py
```

Needs Python 3.8+, Pillow, Playwright's Python package and any Playwright installation
that left a Chromium and its FFmpeg build on the machine.
